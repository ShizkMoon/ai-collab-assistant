# Redmi AX6000 原厂恢复材料

适用设备：本次实际识别的 Redmi AX6000，型号 RB06，原厂固件 1.0.67。备份和恢复材料保存在本机，尚未在设备上实际触发 TFTP 恢复。

## 备份范围

相邻的 `ax6000-oem-backup` 目录保存完整 128 MiB NAND 读取结果及 10 个命名分区，共 11 个分区文件。每个文件都与设备上的临时快照核对了 MD5，另保存本地 SHA-256 和实际字节数，见该目录的 `manifest.json`。文件是经过 ECC 读取的数据，不含 OOB。

这些分区快照产生于 SSH 解锁之后。解锁前的 Dropbear 脚本、shadow 和 NVRAM 文本分别保存为 `dropbear.before-codex`、`shadow.before-codex`、`nvram.before-codex`。运行中的原厂 overlay 可能在各次读取之间发生变化，整片备份和分区备份不宣称是同一时刻的文件系统快照。

备份含设备专属无线校准数据和私有配置，目录访问权限已限定到当前 Windows 用户、SYSTEM 和管理员。不要把其他设备的 Factory、Bdata、BL2 或 FIP 写入本机。

## 固件与校验

原厂完整恢复包：`miwifi_rb06_firmware_847e9_1.0.48.bin`。

- 大小：20,972,472 字节。
- MD5：`0d10c91c5816a29c5a785d0e09c847e9`，与小米服务器的 Content-MD5 和 ETag 一致。
- SHA-256：`ba5c3b0beb08f374ee7143daaddb523c0e60e351a61fa587907695fcf8112637`，本机计算。
- [小米官方恢复包来源](https://cdn.cnbj1.fds.api.mi-img.com/xiaoqiang/rom/rb06/miwifi_rb06_firmware_847e9_1.0.48.bin)。

`MIWIFIRepairTool.x86.zip` 来自[小米官方恢复工具地址](https://bigota.miwifi.com/xiaoqiang/tools/MIWIFIRepairTool.x86.zip)，已下载，未运行。其本地 SHA-256 为 `436e57a5e2daf1c5b4ece8851a7b7517c1fbc9e69acba8fac3806aa160f251b5`。

## 恢复路径

本次已永久安装 stock 版 OpenWrt，保留原厂 BL2 和 FIP。永久安装已重建原厂 ubi、ubi1 和 overlay 所在区域；恢复原厂需要重新写入恢复包，不能只切换启动槽。实际运行版本为 OpenWrt SNAPSHOT `r37185-f29dfe25ba`，已确认从 squashfs 启动并完成一次实际重启。

原厂 U-Boot 的 LAN 恢复使用 DHCP 和 TFTP。上游设备页提供的手动恢复参数是：电脑以太网设为 `192.168.31.100/24`，不给调试网卡填写默认网关和 DNS；DHCP 只给路由器分配 `192.168.31.2`。此时路由器通常请求 `C0A81F02.img`，即分配地址的十六进制形式。可将完整原厂恢复包复制并改成这个名称；实际请求名必须以 TFTP RRQ 日志为准。

手动恢复时，断开路由器电源，按住 Reset 再通电；按上游说明观察橙灯闪烁后重新常亮，再松开按键。等待恢复写入和蓝灯完成信号，期间保持供电。上述协议与灯态来自上游说明，尚未在本机验证；不要为了测试恢复而在正常系统上随意触发。

小米恢复工具可作为替代入口。它可能需要 Windows 防火墙及管理员操作；本任务没有预先改变这些设置。

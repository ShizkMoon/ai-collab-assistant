# 设计原则

## 约束先行

让环境本身承载约定（目录结构、规则文件、服务单元），而不是依赖每次会话里的口头指令。Agent 读到什么规则，就应该等于系统真正的边界。

## 单一来源

同一事实只在一个地方维护，其余入口用链接、软链或生成物指过去。需要"同一份内容多处生效"时，选引用而不是复制。

## 作用域分层

- 全局层：适用于所有工作的机器级约定（如全局 `AGENTS.md`）。
- 域层：某一棵目录树的约定（如数据盘自己的 `AGENTS.md`）。
- 项目层：单个作品的 `AGENTS.md` / `.devin/` 规则。

上层不该重复下层细节；下层可以收紧，不推翻上层。

## 可回退

每个自动化、迁移、兼容补丁都附带回退路径和证据；不可逆操作必须显式确认。

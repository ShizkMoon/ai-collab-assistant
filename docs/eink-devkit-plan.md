# 电子墨水改造两条路线(设计,未动工)

背景:KPW5 疑似板级损坏(零枚举 bootloop,见排障记录)。两条出路——**A. 榨干它的屏和壳**;**B. 直接买现成套件**。后者保体验,前者是工程玩具。

## 路线 A:KPW5 拆件改造(agent 深度辅助)

### 可用件盘点

| 部件 | 状态 | 可复用度 |
| --- | --- | --- |
| **6.8" E Ink Carta 1200 屏 + 触摸 + 前光** | 一体模组,排线待查型号 | 中——要看驱动支持 |
| **外壳/前框** | 完好 | 高——直接当壳用 |
| **电池** | 健康(3.8V 锂电) | 高——拔插式,直接进新项目 |
| **主板** | 砖 | 零——SoC 锁死,不可能刷 |

### 实施设想(按依赖排)

1. **识别屏型号**:拆开前面板(屏幕胶粘,热风+撬片,小心),看背面 ED0xxx 丝印。这是整方案的可行性门槛——查到型号先停,决定继续还是放弃
2. **驱动选型**(二选一):
   - **若有现成支持**(epdiy 兼容列表/Good Display 模块):ESP32-S3 驱动板 + 转接排线,改个座子就能跑
   - **若无现成支持**(PW5 大概率在此列):自研驱动 = 逆向 EPDC 波形表 + 电源时序板,**工程量太大,不建议**
3. **走通后的目标形态**:KPW5 外壳 + 自研/适配驱动板 + ESP32-S3 主控 + 原机电池 → 一个"Kindle 外壳的电子墨水实验机"

### 工程量估算(诚实版)

- 拆屏定型号:1-2 小时,有风险(胶+玻璃)
- 若型号恰有支持:画转接板(立创 EDA 打样)+ 调固件 ≈ 1-2 周业余量
- 若型号不支持:自研驱动 ≈ 数周到数月,大概率烂尾——**建议是:查到不支持就停手,屏单独卖**

### 我(agent)能包的活儿

查型号兼容、画转接板原理图参考、跑驱动固件、配 ESP32 工具链、调试输出——软件面全包;硬件焊接/拆装风险在实体侧。

## 路线 B:现成套件(推荐,保体验)

选型按"屏幕支持完善 + 开发易用"排:

| 套件 | 屏 | 驱动 | 开发 |
| --- | --- | --- | --- |
| **epdiy V7 + 官配屏** | 在售 ED060/ED097 系列(4.7"-9.7" 多型号)| 开源 ESP32 驱动,波形社区已验 | ESP-IDF/Arduino,例程现成,**开发门槛最低** |
| **Waveshare e-Paper 系列** | 1.54"-13.3" 全覆盖,黑白/三色/四色 | 官方驱动板+Arduino/RPi/STM32 例程 | 中文文档全,生态最熟,**国内购买最方便** |
| **Good Display(GDEW 模组)** | 工程级,E Ink 直供 | 官方驱动板/数据手册 | 偏工程向,接口干净,适合当产品验证 |

### 最终体验(每个方案的"你拿到手是什么")

- **路线 A(改造)**:一台"Kindle 外壳的 ESP32 实验机"——外观是 KPW5,但内部是开发板+原屏;刷固件=走 ESP32 OTA/USB;KOReader 无关,是你自己写的应用(天气面板/副屏/阅读器裸机)**成就感高,体验是"DIY 仪器"而非"阅读器"**
- **路线 B(买套件)**:**几小时内就能亮屏**——epdiy/Waveshare 买回家 USB 一插,跑官方 demo;要写功能改 Arduino 代码即可。后续想接 MQTT/Home Assistant/局域网都随你,是"开发板"体验

### 建议的组合拳

**B 先买**(Waveshare 或 epdiy,几百块,马上有得玩)→ **A 当并行项目**:KPW5 壳留着,等哪天社区出了 PW5 屏的支持或你想啃硬骨头再动;主板若真砖则只当料板。

两条路线的产物不冲突:A 是长期工程,B 是立刻能用的工具。

## 未决项

- A 路线第一步卡在"屏型号识别"——拆屏前建议先确认你想做(前面板粘合拆装有碎屏风险)
- B 的具体型号选型(epdiy 6" vs Waveshare 7.5")等你定了预算和用途再细化
- 改造产物是否接你的大系统(Hermes 当下发任务的显示终端)——等活了再说

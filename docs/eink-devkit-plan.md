# 墨水屏改造方案评估（KPW5 拆机屏复用 vs 现成开发套件）

> 状态：方案评估定稿 · 关联文档：[墨水屏硬件选型](eink-display-modules.md)、[epdiy 内部机制](epdiy-internals.md)

手头有一台主板故障（无法 USB 枚举、反复重启）的 Kindle Paperwhite 5（KPW5）。针对这台故障机的去向与桌面墨水屏看板的获取方式，评估两条技术路线：**路线 A（拆解复用 KPW5 的 6.8" 原装屏与外壳）** 与 **路线 B（直接采购现成开源开发套件）**。

## 1. 路线 A：KPW5 拆机面板驱动改造评估

### 1.1 故障机可用部件盘点

| 拆机部件 | 物理状态 | 可复用性评估 |
| --- | --- | --- |
| **6.8" E Ink Carta 1200 面板（`ED068KC1U1`）+ 电容触摸 + 前光层** | 屏幕完好 | 中等：需制作 FPC 转接板并移植 `epdiy` 并口时序与波形表 |
| **机身外壳与前框** | 完好 | 高：可直接作为改装后的外壳 |
| **原装 3.8V 锂电池** | 健康度良好 | 高：标准排线接口，可直接接入 ESP32-S3 开发板充放电电路 |
| **原机主板（MT8113）** | 硬件损坏 / 安全启动锁死 | 零：仅作废板处理 |

### 1.2 驱动原装面板所需的四项工程条件

驱动 KPW5 拆机裸屏需要补齐以下四项软硬件环节，其中波形表可直接从官方固件包解包提取，无需使用示波器盲猜：

| 环节 | 实现难度 | 技术方案 |
| --- | --- | --- |
| **1. 高压驱动电源电路（±15V / +22V / −20V / VCOM）** | 中 | 直接复用开源 **epdiy v7** 的 **TPS65185 PMIC** 参考原理图与 BOM 打板 |
| **2. FPC 排线转接** | 低 | 根据面板背面丝印引脚定义绘制 0.5mm 间距 FPC 转接板（嘉立创打样） |
| **3. ESP32-S3 并口刷屏固件** | 中高 | 基于 `epdiy` 的 `output_lcd`（LCD_CAM 外设 + GDMA + RMT）框架配置 `displays.c` 分辨率与行选通时序 |
| **4. 面板原厂波形表（Waveform）** | 可从固件提取 | KPW5 官方恢复包（`update_kindle_pw5*.bin`）的 RootFS 中包含该面板的原厂 `.wrf` 波形文件与 Regal 4 查找表（已通过 `~/Repo/kpw5-analysis` 完成格式解析），可编写脚本离线转换为 `epdiy` 的 `EpdWaveform` C 头文件 |

### 1.3 风险与投入产出评估

- **拆屏物理风险**：KPW5 前框与玻璃基板采用高强度结构胶粘合，加热拆解存在压碎玻璃基板或撕裂 FPC 排线的风险。
- **硬件调试周期**：首次绘制 FPC 转接板加调通 TPS65185 上电时序预计需耗费 1–2 周业余时间，且需配合万用表与示波器实测各路高压轨。
- **自动化辅助边界**：固件解包、`.wrf` 波形转换脚本、KiCad 原理图检查与 ESP-IDF 驱动代码编写均可由 Agent 完成；但加热拆屏、FPC 焊接与硬件上电排障必须由人工操作。

### 1.4 路线 A 止损检查点

若决定开展路线 A 硬件 DIY，严格按以下顺序分步推进，任一步受阻即停止投入：

1. 先完成软件侧准备：从 KPW5 固件镜像中提取 `ED068KC1U1` 波形数据并转换为 `epdiy` 头文件格式。
2. 加热拆下屏幕，核对 FPC 引脚定义是否与标准并口 EPD 吻合；若为非标私有接口则直接将屏幕总成挂闲鱼出售，不再画板。

## 2. 路线 B：直接采购成熟开源套件（主力推荐）

为快速跑通助理系统的桌面显示闭环，优先采购硬件与驱动已完全成熟的现成套件：

| 开发套件 | 屏幕规格 | 驱动栈 | 核心优势 |
| --- | --- | --- | --- |
| **LilyGo T5 4.7" E-Paper（ESP32-S3）** | 4.7" 960×540（ED047TC1/TC2） | **epdiy v7** 原生支持 | 板屏一体、自带 TPS65185 电源芯片与锂电池接口，通电即可刷入固件使用 |
| **epdiy v7 开源驱动板 + ED060/ED097 面板** | 6"–9.7" 多款标准并口屏 | **epdiy v7** 官方硬件 | 波形与时序已在主线仓库验证完备 |
| **Waveshare / 佳显 SPI 墨水屏套件** | 1.54"–7.5" 黑白/三色 | ESPHome 原生集成 | 适合低频刷新的墙面看板，零代码接入 Home Assistant |

## 3. 综合结论

**主线任务直接采用路线 B（采购 LilyGo T5 4.7" 配合汉朔拆机 ESL 价签）**，当天即可接入 [统一渲染管线](render-pipeline.md) 投入日常使用；KPW5 故障机留作闲暇时的独立硬件 DIY 练手项目（路线 A），不阻塞助理系统的进度。

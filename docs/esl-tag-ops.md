# 电子价签（ESL）刷机、硬件鉴别与采购验收手册

> 状态：实操参考手册 · 关联文档：[OpenEPaperLink 内部机制](oepl-internals.md)、[墨水屏交互设计](eink-modules-ux.md)、[E-Ink 技术术语表](eink-tech-glossary.md)
>
> 本文汇总二手拆机 ESL 电子价签从闲鱼选购、不开壳鉴别主控芯片、收货验机、有线首刷开源固件到故障排查的完整操作流程。

## 1. 各主控芯片家族的刷机路径对比

二手电子价签能否刷入 OpenEPaperLink（OEPL）开源固件，**完全取决于内部搭载的主控 SoC 芯片，而非外壳尺寸或商品名称**（同一外壳型号的不同生产批次可能搭载完全不同的芯片）。

### 1.1 主控芯片可刷性总览

| 主控 SoC | 代表价签型号 | 首次刷机方式 | 烧录接口 | 原厂固件能否备份 | 刷死救砖难度 | 综合推荐度 |
|---|---|---|---|---|---|---|
| **TLSR8359 / 8258** | **汉朔 Stellar / Nebular（白框 4.9V 批次）**、Gicisky | 有线串口（Gicisky 支持免拆机蓝牙 OTA） | 单线 **SWS**（可用普通 3.3V USB-TTL 的 `TX` 引脚直接模拟）+ `NRST` + `3V3` + `GND` | 原厂启用了 Flash 读保护，首次烧录需执行 `Unlock`（全片擦除） | SWS 固化在芯片 Boot ROM 中，断电重连即可重刷 | **五星推荐（闲鱼主力首选）** |
| **ZBS243 / SEM9110** | **Solum M2 全系**（`ST-GR` / `ST-GM`） | 有线治具 | 自定义 4 线类 SPI 接口（`CLK`/`CS`/`MOSI`/`MISO`）+ `RST` + 受控电源脚 | **可完整备份**：无读保护，刷前必须先导出 64KB Flash 与 1KB Infopage | ROM 层调试口，断电重启即可重刷 | **五星推荐** |
| **nRF52811** | Solum M3 Newton（`EL0xxH3WRA`） | 有线 SWD | 标准 ARM SWD（复用电池仓测试焊盘） | 启用了读保护，解锁即全擦 | 使用 CMSIS-DAP / J-Link 执行 Mass-erase 后重刷 | 四星推荐 |
| **EFR32xG22** | Solum M3 SiLabs 版（`EL0xxF5` / `F6`） | 有线 SWD | ARM SWD 5 线 | **解锁全擦前必须先备份 `0x0FE00000` 处的 1KB User Data**（存有屏幕硬件配置，丢失后无法驱动屏幕） | 保留了 User Data 即可随时重刷 | 三星半（注意备份 UD） |
| **CC1110** | DisplayData Chroma 29 / 42 / 60 / 74 | 有线调试口 | TI Debug（`DC` / `DD` / `RESETn`） | 可完整备份 | 无锁重刷；若低压导致 EEPROM MAC 丢失可用 `patch_sn.py` 修复 | 三星（需 Sub-GHz AP） |
| **MSP430G2553 + A7106** | 老款汉朔 Stellar-M（主板丝印 `HS_EL5102`） | **不支持 OEPL** | - | - | 无 OEPL 固件支持，仅能拆下 SPI 裸屏自配驱动板 | **避坑勿买** |
| **CC2640R2F** | 汉朔 Stellar 黑框 6.24V 批次 | 非 OEPL 生态 | JTAG（需 XDS110） | - | 仅有第三方独立 BLE 固件（`ihopebleepd`），不接入 OEPL AP | **避坑勿买** |
| **DA14585 / 智控 6626** | 盒马定制 4.2" / 小米智控价签 | **不支持 OEPL** | - | - | 无开源 OEPL 固件 | **避坑勿买** |

### 1.2 汉朔 TLSR8359 / 8258 系列：USB-TTL 四线首刷步骤

汉朔 Stellar-M（2.13"）、Stellar-L（2.9"）、Stellar-XL（4.2"）及 Nebular 系列的烧录触点直接位于背面电池仓盖下方，掀开卡扣式电池盖即可看到标注清晰的焊盘（**切勿从正面撬透明前盖，老款前盖为胶粘，撬正面极易压碎墨水屏玻璃**）。

**USB-TTL（必须使用 3.3V 电平，推荐 CH340G / CP2102）接线对应表**：

| USB-TTL 端引脚 | 价签主板焊盘丝印 | 接线说明 |
|---|---|---|
| `TXD` | `SWS`（或标为 `RXD` / `SWS_RXD`） | **唯一的数据线**（通过 UART TX 波特率时序模拟 Telink SWS 单线协议） |
| `RTS` 或 `DTR` | `NRST`（或 `RST`） | 自动拉低复位引脚进入烧录态（若 TTL 模块无 RTS/DTR，可在点击烧录瞬间手动将 `NRST` 短接一下 `GND`） |
| `3V3` | `VCC` / `3V3` | **严禁接 5V**，烧录期间需取下纽扣电池 |
| `GND` | `GND` | 共地 |
| `RXD` | 悬空不接 | 单线写入无需接 `RXD` |

**网页端免安装烧录步骤**：

1. 使用桌面端 Chrome 或 Edge 打开 [`atc1441.github.io/ATC_TLSR_Paper_UART_Flasher.html`](https://atc1441.github.io/ATC_TLSR_Paper_UART_Flasher.html)。
2. 波特率保持默认 `460800`，点击 `Open` 选择对应的 USB-TTL 串口。
3. **首次刷机必须先点击 `Unlock Flash`**：解除原厂固件的写保护（等效于全片擦除）。
4. 选择下载好的 `OpenEPaperLink_TLSR`（或 `ATC_TLSR_Paper`）`.bin` 固件文件，点击 `Write to Flash`，约 10–15 秒写入完成。
5. **关键步骤：刷完后必须先断开 TTL 的 `TXD` 数据线并重新装回电池**（若挂着 TTL 的 `TXD` 线，芯片会保持在 SWS 调试态，蓝牙广播无法启动）。
6. 首次有线刷入后，后续所有固件更新均可直接通过蓝牙无线 OTA 完成。

### 1.3 Solum M2（ZBS243）系列：Pogo Pin 治具刷机步骤

Solum M2 系列的 10 个标准测试焊盘同样位于背面电池仓盖内侧（无需拆解外壳）。由于 ZBS243 采用自定义 4 线 SPI 调试时序，且进入调试模式需要在芯片上电复位瞬间向 `CLK` 发送特定握手节拍，必须使用一块 **ESP32-S2（如 Wemos S2-Mini，约 ¥15）** 刷入官方 `Tag_Flasher` 固件充当编程器，并将价签的 `VCC` 接在编程器受控的电源引脚（或 MOSFET 开关）上。

```bash
# 1. 首次刷写前必须完整备份原厂 64KB Flash 与 1KB Infopage（内含原厂唯一 MAC 地址与校准值）
python3 OEPL-Flasher.py -p /dev/ttyACM0 -z read backup_flash.bin
python3 OEPL-Flasher.py -p /dev/ttyACM0 -z -i read backup_infopage.bin

# 2. 刷入 OEPL 固件（脚本会自动将 Infopage 中的原厂 MAC 保留写入新固件）
python3 OEPL-Flasher.py -p /dev/ttyACM0 -z write ZBS243_OEPL_Full.bin
```

刷写完成后拔下编程器、装回 CR2450 电池（注意先短接一下电池座正负极放掉板载电容余电以触发完整上电复位），屏幕刷出 OEPL 启动画面即告成功。

## 2. 无线刷机（OTA）边界与"锁区件"真相

### 2.1 原厂未拆封价签能否不接有线直接隔空刷入 OEPL？

- **Gicisky / Picksmart 蓝牙价签**：**支持免拆机纯无线刷入**。其原厂固件默认开放了标准 Telink BLE OTA 服务，可直接用 Chrome 打开 [`atc1441.github.io/BLE_EPaper_OTA.html`](https://atc1441.github.io/BLE_EPaper_OTA.html) 无线刷入开源固件。
- **汉朔（Hanshow）与 Solum（M2/M3）商超拆机件**：**首次必须通过电池仓焊盘有线刷入**；有线首刷一次后，后续终身支持无线 OTA。

### 2.2 闲鱼卖家话术与技术事实对照

| 闲鱼卖家常见描述 | 对应的真实硬件状态 | 采购决策建议 |
|---|---|---|
| `"已刷开源固件 / 可手机蓝牙传图"` | 已由上家完成有线首刷（通常已刷入 `ATC_TLSR_Paper`） | **最省事**：到手装电池即可被 OEPL AP 直接识别，省去接线首刷步骤 |
| `"退店锁机 / 绑定原超市基站 / 不可配网"` | 原厂固件的配置文件里记录了原超市 AP 的信道与密钥 | **完全不影响刷 OEPL**：有线首刷会整片擦除原厂固件，锁不锁店毫无区别，切勿为所谓的"原厂未锁版"多付溢价 |
| `"仅通电显示 / 内部芯片不详 / 售出不退"` | 卖家未区分批次，大概率混有老款 MSP430 或 CC2640 不可刷批次 | 按下方 §3 要求卖家拍电池仓照片核对，不给拍则按纯买裸屏价格估价 |

## 3. 标签硬件鉴别方法（避开不可刷批次）

### 3.1 不拆壳通过外观与背贴鉴别主控芯片

| 品牌系列 | 外观或背贴鉴别特征 | 内部主控芯片结论 |
|---|---|---|
| **Solum M2** | 背面型号贴纸以 **`ST-GR`** 或 **`ST-GM`** 开头（如 `ST-GR29000`） | **ZBS243**（100% 兼容 OEPL） |
| **Solum M3** | 背贴型号为 **`EL0xxH3WRA`** 为 **nRF52811**；型号为 **`EL0xxF5` / `F6`** 且条码旁印有 **`Silabs`** 字样为 **EFR32xG22** | 均兼容 OEPL（注意避开 `EL029GSWRN` 等少见的 CC2630 批次） |
| **汉朔 Stellar E31A 批次（关键区分点）** | 看正面右上角 **LED 指示灯窗口周围的塑料小框颜色**：**白色小框（屏印 4.9V）= TLSR8359（可刷）**；**黑色小框（屏印 6.24V）= CC2640R2F（不兼容 OEPL）** | 下单前务必看正面右上角 LED 框颜色 |
| **汉朔电池仓内主板丝印** | 掀开后盖看 PCB 丝印：**`HS_EL5102` 为老款 MSP430（不可刷）**；印有 `SWS` / `TXD` / `NRST` 单排焊盘的为 **TLSR8359（可刷）** | 拍一张打开电池盖的照片即可 100% 确认 |
| **汉朔 Nebular 系列** | 背贴为 `Nebular-266` / `350` / `420` 等 | 全系均为 **TLSR8258 / 8359**，但注意避开后缀带 **`Pro`** 的胶封一次性电池款（见 §3.2） |
| **Pricer 全系** | 正面边框带有黑色半透明**红外接收窗** | 红外通信且程序运行于 RAM，无法直接刷固件（需焊接替换主控板） |
| **Gicisky 2.13" 警惕假墨水屏** | 部分同模具型号实为反射式 **TFT LCD**（商品页常宣传"无闪烁秒刷"） | 断电后画面消失，且不支持 OEPL BLE-AP，选购时认准电子墨水屏（EPD）款 |

### 3.2 各型号电池规格与更换注意事项

| 价签型号 | 电池规格与数量 | 更换维护说明 |
|---|---|---|
| Solum M2 1.54" | 1 × CR2450 | 卡扣后盖直开 |
| 汉朔 Stellar 2.13" / 2.9"、Solum M2 2.9" | 2 × CR2450（并联） | 卡扣后盖直开，日常最通用规格 |
| Solum M2 4.2" / 7.5" | 2–4 × CR2450 | 换电池时成组同时更换 |
| Solum M3 13.3"（`EL133`） | 4 × AAA（7 号电池，2 串 2 并） | 必须四节使用同品牌新电池同时更换，防止新旧混用反充 |
| **汉朔 Nebular Pro 超薄款** | **内置不可拆卸 LiMnO2 软包电池 + IP68 全胶封外壳** | **一次性结构，没电需暴力破壳改线，不建议日常购买** |

## 4. 采购前询问与收货 10 分钟验机流程

### 4.1 下单前向卖家确认的三张照片

1. **正面全貌照**：检查墨水屏四角是否有碎裂黑斑，如果是汉朔 Stellar 则确认右上角 LED 窗口为**白框**。
2. **背面型号贴纸照**：核对具体型号字符串（如 `ST-GR29000` 或 `Stellar-L3N@ E31A`）。
3. **打开电池盖后的仓内焊盘照**：一眼排除 `HS_EL5102`（MSP430）老板与焊盘被腐蚀的泡水件。

### 4.2 收货验机标准步骤

1. **外观与排线检查**：观察屏幕边缘玻璃有无暗裂（墨水屏玻璃极薄，边角受压碎裂后局部会无法刷新）。
2. **板载电容彻底放电复位**：Solum M2/M3 等标签无独立上电复位（POR）芯片，且板载大电容余电可维持数分钟。拔下旧电池后，**用镊子短接电池座正负极触点 2 秒放尽余电**，再装入新 CR2450 电池。
3. **首刷前先备份（ZBS243 与 EFR32 必做）**：
   - ZBS243：先运行 `read` 与 `-i read` 备份原厂 Flash 与 Infopage；
   - EFR32xG22：先运行 `reflash.py --dump-ud` 备份 1KB User Data。
4. **刷入 OEPL 固件并验证入网**：写入固件 → 断开烧录线 → 放电重新装入电池 → 观察屏幕刷出 OEPL 引导页并在 AP 管理后台看到该 MAC 上线 → 发送一张全黑/全白/红色测试图确认无断线坏道。

## 6. 常见故障排查表

| 故障现象 | 常见原因与排查方法 |
|---|---|
| **AP 显示传输完成（Xfer Complete），但屏幕画面完全不刷新** | 1. **纽扣电池内阻过大**：旧 CR2450 空载万用表测仍有 3.0V，但刷屏开启高压升压泵瞬间电压跌落至 2.1V 以下导致复位，更换全新品牌 CR2450 即可解决；<br>2. **屏型定义（`hwType`）不匹配**：刷入了错误分辨率或驱动 IC 的固件变体；<br>3. **板载升压电感或 MOS 管损坏**：刷屏时手摸电感发烫且电流飙至 100mA 以上，属硬件损坏 |
| **汉朔 TLSR 刷完固件后，手机或 AP 搜不到蓝牙广播** | **未拔掉 USB-TTL 的 `TXD`（`SWS`）线**：SWS 引脚保持连接时会阻止芯片进入正常蓝牙广播模式，拔掉烧录线并放电重装电池即可 |
| **更换新电池后仅几天就耗尽电量** | 串联万用表测量睡眠态电流：正常应在 **2–8µA** 之间；若睡眠电流达数百微安甚至数毫安，通常为面板 COG 驱动芯片漏电或板载滤波电容微短路，直接淘汰该标签 |
| **Sub-GHz 标签始终无法连接 AP** | 检查 AP 侧是否使用了廉价绿板 CC1101 模块（晶振频偏严重导致无法解调），更换为 **亿佰特 E07-900M10S** 并确认频段（868MHz / 915MHz）一致 |

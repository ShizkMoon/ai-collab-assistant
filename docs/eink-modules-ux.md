# 墨水屏模块体验设计方案

视角:不是"买一堆屏",是**给家里装一套环境智能**——信息长在对的地方,
路过扫一眼就有答案,永不打扰。配套选型:`eink-display-modules.md`;
OEPL 兼容表筛选:`resources/tagtypes/` 全量 JSON(2026-10 拉取)。

## 1. 体验原则(先定规矩再选件)

| 原则 | 落地含义 |
|---|---|
| **2 秒可读** | 单屏只放一条主信息+一行上下文;字大到隔 2m 能读 |
| **零打扰** | 无背光无声音无弹窗;更新只是"纸换了一页" |
| **永远在线** | 断电也留最后帧;断网显示 stale 时间戳,诚实不装死 |
| **一屏一事** | 不做轮播/菜单/层级——要看别的信息,贴第二个标签 |
| **无输入** | 纯显示;交互归手机/voice agent,屏不揽活 |

## 2. 点位地图(场景→模块→内容)

| 位置 | 模块 | 显示内容 | 刷新节奏 |
|---|---|---|---|
| 桌面主位 | LilyGo T5 4.7" | **助手卡**:agent 当前任务+今日日历 TOP3+通知队列 | 5-15min / 事件触发 |
| 门厅/过道墙 | 7.5"(ESL 或佳显) | **全局看板**:系统总览+日历墙+今日天气 | 15-30min |
| 冰箱 | 2.9" ESL | 购物清单/食材提醒/留言条 | 按需 |
| 设备贴身 | 1.54-2.13" ESL ×N | 各设备状态:NAS 温度/打印机纸量/植物湿度/充电桩 | 5-30min |
| 门口/书房门 | 11.6" ESL | **空间标牌**:房间名+状态(勿扰/在会中) | 按需 |
| 绿植旁 | 2.13" ESL | 土壤湿度+上次浇水 | 1h |

布局心法:**标签长在物上,卡片长在桌上,看板长在墙上,标牌长在门上**。
先从"一台设备+一个标签"的配对开始,有用再加,不一次铺满。

## 3. 内容设计(每屏画什么)

```
┌─ 标签级(1.5-2.9")─────────┐
│ NAS        42°C   ████░░ │  ← 图标+大字数值+迷你进度条
│ updated 12:30           │  ← 底部 stale 时间戳(必有)
└─────────────────────────┘
┌─ 卡片级(4.7")───────────────┐
│ ▸ 当前任务:固件逆向 wave-7   │  ← 头部:agent 在干嘛
│   今天  14:00 例会          │
│   待办  ·寄修问价 ·下单DAM线 │
│   ─────────────────        │
│   🔔 3条新通知  12:30      │
└─────────────────────────┘
┌─ 看板级(7.5-11.6")──────────┐
│ 系统 ●●●○  日历|三 通知|4   │  ← 多栏,每栏仍是"一屏一事"
│ ██  ██  ██  ██  ██        │
└─────────────────────────┘
```

渲染规矩(沿用 KPW5 原则):4 灰抖动出图、小更新用 partial、
每 ~20 次 partial 插一次全刷、避免大面积黑白反转。

## 4. 采购清单(筛过的 OEPL 兼容型号)

**射频路线先选**(决定 AP 网关):

| 路线 | 标签家族 | AP 硬件 | 判定 |
|---|---|---|---|
| **BLE 路径** ⭐ | 汉朔 HS/TLSR 系(闲鱼主力货) | ESP32-S3 刷 OEPL BLE-AP 固件,~¥60-150 | **推荐**:闲鱼上汉朔拆机件最多最便宜 |
| sub-GHz 路径 | M2/M3 系(ZBS243/Newton) | Mini AP v4(ESP32+CC1101/EFR32,~¥150-300) | 备选:克隆件多但 AP 件贵些 |

**按梯队筛出的具体型号**(全在兼容表内):

| 梯队 | 型号(tagtypes ID) | 分辨率 | 闲鱼搜索词 | 估价 |
|---|---|---|---|---|
| T1 设备贴 | **HS BW 2.13"(54)** / HS BWR 2.13"(55) | 256×128 | `汉朔 价签 2.13` | ¥10-30 |
| T1 通用 | **M2 2.9"(01)** / HS BWRY 2.9"(6E) | 296×128 | `电子价签 2.9 墨水屏` | ¥20-50 |
| T1 彩色 | M3 2.9" BWRY(2B)/ HS BWRY 2.9"(6E) | 384×168 | 三色款,红黄点缀 | ¥40-80 |
| T3 看板 | **HS BWR 5.83"(6A)** / M2 7.4"(05) | 648×480/640×384 | `价签 5.8/7.5 墨水屏` | ¥80-250 |
| T4 大标牌 | **HS BWRY 7.5"(6B)** / M3 11.6"(37) | 800×480/960×640 | `汉朔 价签 7.5/11.6` | ¥200-500 |
| 桌面卡 | LilyGo T5 4.7"(非 ESL,ESP32 一体板) | 960×540 | `LilyGo T5 墨水屏` | ¥150-280 |

注:BWR=黑白红三色,BWRY=四色,刷新更慢但状态点缀好用;
纯 BW 刷得最快——状态贴优先 BW,装饰位才上彩色。

## 5. 最小落地路径(¥300-500,一周内可玩)

1. **下单**:ESP32-S3 开发板(¥40-60)+ HS BW 2.13"×3(¥30-90)+
   LilyGo T5 4.7"(¥150-280)
2. **刷 AP**:ESP32-S3 刷 OEPL BLE-AP → 标签上电自动入网
3. **渲染服务**:本机起一个 `image-render` 小服务(HTML→PNG+meta),
   OEPL AP 的 HTTP push 接口直接喂
4. **第一屏**:T5 显助手卡;三个标签分别贴 NAS/打印机/绿植
5. **验收**:断网关 10 分钟,标签仍显最后帧+stale 时间戳=达标

## 6. AP 网关刷机预备(货未到,步骤先备)

固件源:`github.com/OpenEPaperLink/OpenEPaperLink/releases`(v3.00+)。
按板子选 bin(`_full.bin` = 合并镜像,单文件烧 0x0 即可):

| AP 硬件 | 固件 | 适用 |
|---|---|---|
| **任意 ESP32/ESP32-S3 开发板** ⭐ | `BLE_ONLY_AP_full.bin` | **BLE 路线就选它**——裸板即网关,不带 sub-GHz 射频 |
| ESP32-S3 16MB/8MB 板 | `ESP32_S3_SIMPLE_AP_full.bin` | 带全套 AP 功能的 S3 板 |
| LilyGo T-Display 等成品 | `ESP32_S3_16_8_LILYGO_*` 系列 | 按板型号选 |
| Mini AP v4 成品 | `OpenEPaperLink_Mini_AP_v4_full.bin` | sub-GHz 路线才需要 |
| ESP32-C6/H2 小板 | `OpenEPaperLink_esp32_C6/H2` 对应 bin | 新芯片备选 |

### 刷写步骤(两条路,任选)

**A. Web 刷机器(最简单)**:Chrome/Edge 打开 OEPL 官方 web flasher
(仓库 wiki 首页有链)或 `espressif.github.io/esptool-js` → 接 USB →
选 `BLE_ONLY_AP_full.bin` → 烧 0x0 → 复位。无需装任何软件。

**B. esptool CLI(本机现成)**:
```bash
pipx run esptool --chip esp32s3 -p /dev/ttyUSB0 \
  write_flash 0x0 BLE_ONLY_AP_full.bin
# esptool 可 pip/pipx 装;或 nix profile add nixpkgs#esptool
```

### AP 配网与标签入网

1. 烧完 AP 自起 AP 热点(SSID 形如 `OpenEPaperLink`)→ 手机/电脑连上 →
   Web UI 填家里 WiFi → AP 重启入网,浏览器开 `http://<AP-IP>` 到管理台
2. **标签入网**:标签长按/上电唤醒 → AP 管理台自动发现 → 一键推送
   OEPL 固件到标签(BLE OTA)
3. **锁区注意**:闲鱼下单问卖家"价签能否配网/已解锁否"——部分拆机件
   被原商户锁网,AP 发现不了;能进 AP 管理台的才是好件
4. 推图验证:管理台里给标签发一张测试图→显示即通;之后走
   HTTP API(`POST /imgupload`)交给渲染服务自动喂

### 验收清单

- [ ] AP 热点起得来,Web UI 可进
- [ ] AP 上家 WiFi 后管理台可访问
- [ ] 3 个标签全部被发现且 OEPL 固件推送成功
- [ ] 测试图下发→标签正确显示
- [ ] 拔 AP 5 分钟再插回,标签自动重连

## 7. 未决项

- AP 路线终选:BLE(HS 系)vs sub-GHz(M2 系)——先买 BLE,若闲鱼
  遇到超便宜 M2/M3 再补第二网关,两条射频并存无冲突
- 闲鱼拆机件成色/锁区(部分价签有区域锁,下单问卖家"已解锁可刷机否")
- T5 固件框架选型:自写 Arduino 最小渲染 vs 找现成 ESPHome/HA 集成
- 刷新功耗实测:ESL 号称年续航,5min 级刷新频率下实际几个月

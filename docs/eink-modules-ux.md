# 墨水屏交互与版面设计

> 状态：设计定稿 · 配套选型：[墨水屏硬件选型](eink-display-modules.md) · 调度机制：[多端显示仲裁](surface-arbiter.md) · 术语参考：[E-Ink 技术术语表](eink-tech-glossary.md)

墨水屏在系统中的定位是**环境常显终端（Ambient Display）**：将高频需要确认的信息固定在对应的物理位置上（如门口贴出门清单、书桌放今日待办、床头贴明日首项任务），路过一瞥即可读取，无背光、无声音、无弹窗打扰。

## 1. 五条交互设计原则

| 原则 | 具体设计要求 |
|---|---|
| **2 秒可读** | 单块屏幕仅突出展示 1 条核心信息与最多 3 行辅助上下文；主字号保证在 1–2 米距离内清晰可辨 |
| **零主动打扰** | 无背光、无蜂鸣器提示音；画面更新如同纸张翻页，夜间睡眠时段停止非必要刷新 |
| **断网保留最后有效帧** | 利用墨水屏双稳态特性，断电或断网时物理保留上一帧画面；画面底部固定印有**数据快照时间戳**，方便一眼识别数据是否陈旧（Stale） |
| **一屏一事** | 单块小屏不做轮播、不做多层菜单跳转；需要常驻展示第二类信息时直接增贴一块低成本价签 |
| **纯被动显示** | 墨水屏端不设复杂按键交互；确认或修改任务统一通过手机卡片、桌面 KRunner 或 ThinkSmart View 主控台完成 |

## 2. 宿舍点位与版面分配

| 物理点位 | 选用硬件模块 | 展示内容 | 刷新频率 |

## 4. OpenEPaperLink（OEPL）兼容硬件选购表

采购拆机 ESL 价签前，需先确定无线射频路线（两者可在同一台 ESP32-S3 AP 上并存）：

| 射频路线 | 对应价签芯片家族 | AP 网关硬件需求 | 选型建议 |
|---|---|---|---|
| **BLE 蓝牙路线（推荐起步）** | 汉朔（Hanshow）Stellar / Nebular **TLSR8359 / 8258** 系列、Gicisky | **任意单片 ESP32-S3 开发板**（刷入 `BLE_ONLY_AP_full.bin`，成本约 ¥40） | **首选**：闲鱼上汉朔拆机件存量最大、价格最低，且无需焊接外置射频模块 |
| **802.15.4（2.4GHz）路线** | Solum M2（**ZBS243**）/ M3（**nRF52811** / **EFR32xG22**） | ESP32-S3 + **ESP32-C6 / H2** 协处理器（或 Mini AP v4 成品） | 备选：协议功耗控制极佳，适合后续批量扩展 Solum M2/M3 标签 |

已核对在 OEPL 官方 `resources/tagtypes/` 兼容表内的推荐型号：

| 尺寸分级 | 推荐型号（对应 OEPL `hwType` ID） | 物理分辨率 | 闲鱼搜索关键词 | 单价参考 |
|---|---|---|---|---|
| 小尺寸状态贴 | **汉朔 HS BW 2.13" (`54`)** / HS BWR 2.13" (`55`) | 250×122 / 256×128 | `汉朔 价签 2.13` | ¥8–20 |
| 门口清单贴 | **汉朔 HS BWRY 2.9" (`6E`)** / Solum M2 2.9" (`01`) | 296×128 | `电子价签 2.9 墨水屏` | ¥15–35 |
| 中尺寸看板 | **汉朔 HS BWR 5.83" (`6A`)** / Solum M2 7.5" (`05`) | 648×480 / 640×384 | `墨水屏价签 5.8 7.5` | ¥80–220 |
| 大尺寸看板 | **汉朔 HS BWRY 7.5" (`6B`)** / Solum M3 11.6" (`37`) | 800×480 / 960×640 | `汉朔 价签 7.5 11.6` | ¥180–400 |
| 书桌主力屏 | **LilyGo T5 4.7" ESP32-S3**（非 ESL，并口直驱一体板） | 960×540（16 级灰） | `LilyGo T5 4.7 墨水屏` | ¥160–260 |

注：纯黑白（BW）面板全刷速度最快（约 2–3s）；黑白红（BWR）与四色（BWRY）面板全刷需 10–15s，但红色/黄色非常适合用于高亮逾期或紧急标记。

## 5. OEPL AP 网关刷机与配网步骤

### 5.1 选择 AP 固件镜像

从 [OpenEPaperLink Releases](https://github.com/OpenEPaperLink/OpenEPaperLink/releases)（v3.00+）下载对应合并固件（`*_full.bin` 单文件可直接从偏移地址 `0x0` 烧录）：

| AP 硬件板型 | 对应固件文件名 | 适用场景 |
|---|---|---|
| **通用 ESP32 / ESP32-S3 开发板（无外挂射频芯片）** | `BLE_ONLY_AP_full.bin` | 纯 BLE 路线（驱动汉朔 TLSR 与 Gicisky 标签） |
| **ESP32-S3 N16R8（16MB Flash / 8MB PSRAM）** | `ESP32_S3_SIMPLE_AP_full.bin` | 标准 S3 主控板 |
| **Mini AP v4 成品网关** | `OpenEPaperLink_Mini_AP_v4_full.bin` | 同时搭载 ESP32-C6 / CC1101 的多模网关 |

### 5.2 烧录命令

可通过 Chrome / Edge 打开官方网页烧录器（[`install.openepaperlink.de`](https://install.openepaperlink.de/)）一键刷入，或在工作站终端使用 `esptool` 烧录：

```bash
nix run nixpkgs#esptool -- --chip esp32s3 -p /dev/ttyACM0 write_flash 0x0 BLE_ONLY_AP_full.bin
```

### 5.3 AP 配网与标签入网验收

1. **配置 Wi-Fi**：ESP32-S3 烧录完成后自动开启名为 `OpenEPaperLink` 的热点，连接后在配置页填入宿舍 Wi-Fi 密码；重启后在浏览器访问 `http://<AP局域网IP>` 进入管理后台。
2. **标签首刷与上线**：将已刷入 `OpenEPaperLink_TLSR` 或 `ATC_TLSR_Paper` 固件的汉朔价签装入 CR2450 电池（首刷接线方法见 [电子价签刷机与验收 §1.3](esl-tag-ops.md#13-tlsr8359--825x-系列汉朔--giciskyusb-ttl-四线首刷)），AP 管理台将在 1 分钟内自动发现标签并显示电量与信号强度。
3. **接口推图测试**：在工作站执行 `curl -F "file=@test.jpg" -F "mac=<标签MAC>" http://<AP-IP>/imgupload`，确认标签在下一个唤醒周期完成刷屏显示。

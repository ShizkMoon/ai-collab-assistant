# 墨水屏硬件选型（电子价签与桌面看板系列）

> 状态：选型定稿 · 上位文档：[多端显示仲裁](surface-arbiter.md)、[统一渲染管线](render-pipeline.md)
>
> 墨水屏模块作为系统的**低功耗常显输出端**，仅负责接收服务端渲染好的位图并刷新显示。本选型方案结合前期 Kindle Paperwhite 5（KPW5）固件逆向（`D:\repo\kpw5-analysis`）得出的驱动与波形经验，筛选国内现货、开源固件成熟的硬件产品。

## 0. 硬件选型四项标准

1. **国内电商或闲鱼现货**：淘宝、拼多多或闲鱼可直接下单，无需跨国海淘。
2. **开源固件生态成熟**：驱动库与终端固件完全开源，支持本地自建网关或 HTTP/MQTT 直连，不依赖任何厂商私有云。
3. **外观简洁易摆放**：优先选择白色窄边框成品壳体，可直接粘贴在门口、设备表面或立于书桌。
4. **性价比高**：小尺寸状态贴优先采用二手拆机电子货架标签（ESL），桌面主力屏采用 ESP32-S3 一体开发板。

注：文中价格均为近期市场参考价，实际采购前按实时行情核对（详细历史成交价见 [电子价签刷机与验收 §5](esl-tag-ops.md#5-闲鱼市场历史成交价参考人民币)）。

## 2. 统一服务端渲染架构

```
数据源（Taskwarrior 任务库 / Home Assistant / 日历）
  → 工作站渲染服务（HTML/CSS 模板 → Playwright 截图 → 1bpp/4bpp 抖动 PNG）
  → 下发通道：
      · Wi-Fi 并口屏（LilyGo T5 / M5Paper）：终端定时唤醒通过 HTTP 拉取 PNG
      · BLE / 802.15.4 价签（ESL）：推送至 OEPL AP，在标签下次 Check-in 时下发
```

## 3. 从 KPW5 逆向分析提炼的工程准则

| KPW5 固件逆向分析结论 | 转化为本系统的选型与设计准则 |
|---|---|
| 原厂波形表按环境温度划分为 13 个温度区间（Bank） | 选用内置温度传感与波形补偿的驱动栈（`epdiy` 与 OEPL 原生支持） |
| 连续局部刷新会累积电泳粒子鬼影，需配合 Regal 波形或定期全刷 | 版面设计避免大面积反色；局部刷新每累计 20 次自动插入 1 次 `GC16` 全屏刷新 |
| 裸屏高压驱动轨（±15V / +22V / −20V）与 VCOM 需逐屏校准，时序错误易烧毁面板 | **采购集成好 PMIC（如 TPS65185）的成品驱动板或整机价签**，不直接从零焊接裸屏高压电路 |
| 16 级灰度面板在图文混排时直接截断会出现明显色带 | 服务端统一将排版色阶限制为 4 级灰度，并开启 Floyd-Steinberg 误差扩散抖动 |
| SPI 价签屏单次全刷耗时约 2–3 秒（三色屏达 10–15 秒） | 墨水屏坚决不展示秒级跳动的动画或进度条，全部设计为静态翻页式卡片 |

## 4. 首发最小采购组合（预算约 ¥350–500）

1. **ESP32-S3 开发板 × 1**（约 ¥40–60）：刷入 OpenEPaperLink `BLE_ONLY_AP` 固件（兼作网关）。
2. **汉朔 2.13" / 2.9" TLSR 芯片电子价签 × 3**（约 ¥30–90）：分别贴于宿舍门口（出门携物清单）、饮水机/插座旁与绿植旁。
3. **LilyGo T5 4.7" ESP32-S3 墨水屏 × 1**（约 ¥180–260）：放置于书桌显示器下方，常驻展示今日三项核心待办与当前 Agent 任务状态。

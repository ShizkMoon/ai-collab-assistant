# ADR 0003：入口常驻 N100，编排循环与执行留在工作站

云原生 Agent 架构（如 Super-agent 参考架构）通常将无状态 Router 与 Agent Loop 部署在云端，端侧仅保留轻量执行守护进程。本系统采用相反的拓扑：**常驻在 N100 上的入口宿主（DS-Bot）仅负责自然语言意图解析与消息转发，Orca 编排循环、任务库、本地文件、GPU 与应用凭据全部保留在工作站上**。

**决策依据**：视频剪辑、代码开发、逆向分析与本地推理均重度依赖工作站的文件系统、GPU 与桌面环境。若将主编排循环迁至远端，每次本地资源访问都需封装为跨机 RPC；而云端架构所追求的弹性扩容与多租户共享，在单用户场景下并无收益。相反，将轻量入口独立部署在低功耗 N100 上，即可满足手机端随时发送指令与接收通知的需求。

**架构影响**：工作站休眠或关机期间，N100 入口仅负责将重度任务入队并发送 WoL 唤醒包，无法在 N100 本地降级执行重负载任务。这也要求 N100 上的服务保持轻量、无核心独占状态，以便随时在任意低功耗设备上重建。

# ADR 0002：仅对付款、删除、对外发布三类操作设置确认点

系统对常规操作默认放行，仅在涉及**付款、删除、对外发布**三类动作时要求人工确认。可逆操作提供默认 5 分钟的撤销窗口；安装软件包、修改系统配置或调整路由等操作直接执行，出现异常通过 NixOS generation 与 Git 版本历史回滚。

**记录原因**：常见的 Agent 框架往往倾向于为系统配置变更添加逐步审批或工具白名单。但在单人私有环境中，事前审批的交互成本随操作频次线性累加，而真正无法通过版本控制或快照回退的操作仅占极小比例。频繁弹窗确认会导致用户疲劳甚至放弃使用自动化系统。在本系统的运行环境下，完善的可回滚机制比事前审批更有效。

这一决策同时约束了后续架构：系统不引入权限策略引擎、分级审批流或操作审计链。若某项新能力稳定性不足，应降低其自治等级（如限制在 L0 或 L1），而非增加新的确认环节。
